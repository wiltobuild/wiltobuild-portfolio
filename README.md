# WilToBuild Portfolio

Personal portfolio website for Wil Sheppard, an AI builder and software engineer transitioning from Crestron-certified AV automation and systems integration.

## Contents

- `index.html` - page structure and content
- `styles.css` - dark theme, responsive layout, and card UI
- `script.js` - animated node background and reveal animations
- `assets/` - portfolio image assets

The project is intentionally static HTML, CSS, and JavaScript so it can be hosted directly with GitHub Pages.
